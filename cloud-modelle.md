# Cloud-Modelle

## On-Premise
Die IT-Infrastruktur wird selber im eigenen Serverraum/Rechenzentrum betrieben.

## Public Cloud
Die Öffentliche Infrastruktur wird über z.B. AWS gehostet und wird mit anderen Kunden geteilt.

## Private Cloud
Eine Cloud-Umgebung, die nur für ein einzelnes Unternehmen betrieben wird.

## Hybrid Cloud
Eine Kombination aus allen verschiedenen Clouds
